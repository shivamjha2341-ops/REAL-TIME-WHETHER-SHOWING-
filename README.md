# 🌦️ Real-Time Weather App
### 🌍 Discover the Weather Around You — Anytime, Anywhere!
A responsive and user-friendly **Real-Time Weather Application** that allows users to check current weather conditions for different cities around the world. The application displays essential weather information through a clean interface with dynamic weather icons.
## ✨ Features
- 🌡️ **Live Weather Updates** — Fetch current weather information using a weather API.
- 🌍 **City-Based Search** — Search for a city and view its weather conditions.
- 🌤️ **Dynamic Weather Icons** — Visual representations of different weather conditions, including clear skies, clouds, drizzle, haze, and mist.
- 💧 **Humidity Information** — View the current humidity level.
- 📱 **Responsive Design** — Designed to provide a smooth experience across desktop and mobile devices.
- ⚡ **Simple and Intuitive UI** — Clean layout for quick access to weather information.
- 🔄 **Real-Time Data Fetching** — Retrieve updated weather data whenever a new search is performed.
## 🖥️ Tech Stack
| Technology | Purpose |
|---|---|
| HTML5 | Structures the application |
| CSS3 | Styling, layout, and responsive design |
| JavaScript | Search functionality and weather data handling |
| Weather API | Provides current weather information |

## 🚀 Getting Started
Follow these steps to run the project locally.
### 1. Clone the Repository
```bash
git clone https://github.com/shivamjha2341-ops/REAL-TIME-WHETHER-SHOWING-.git
```
### 2. Navigate to the Project Folder
```bash
cd REAL-TIME-WHETHER-SHOWING-
```
### 3. Launch the Application
Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
### 4. Explore the App
Enter a city name and check its current weather conditions.
## ⚙️ How It Works
1. The user enters a city name in the search interface.
2. JavaScript processes the search request.
3. The application requests current weather data from the configured weather API.
4. The returned information is displayed on the screen.
5. Weather icons and relevant details update according to the current conditions.
